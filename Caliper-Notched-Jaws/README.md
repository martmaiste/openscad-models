# Caliper Notched Jaws

Caliper jaw covers for measuring the attack angle of foil wings relative to the front foil.

## Purpose

This project provides 3D printable jaw covers that can be attached to vernier calipers to enable precise measurement of the angle between a foil's stabilizer and the front foil. These measurements are crucial for optimizing foil performance in various applications such as sailing, surfing, and other water sports.

## Design Details

The jaw covers feature notches that allow for accurate measurement of the relative angle between two foil components. The design is specifically tuned for:

- Mannesmann M 825-150 Vernier Caliper Stainless Steel 150 mm

## Compatibility

The default parameters are optimized for the Mannesmann M 825-150 caliper model. However, the design can be adapted for other caliper models by adjusting the dimensions in the OpenSCAD files.

## Usage

1. Attach the jaw covers to your caliper using the provided mounting method
2. Position the caliper jaws against the stabilizer and front foil surfaces
3. Read the angle measurement from the caliper scale
